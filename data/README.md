# Frozen data payload

The definitive study uses a frozen ChEMBL-derived EGFR cohort. To keep the GitHub clone lightweight, the full raw/intermediate/final frozen data payload is distributed in the immutable Zenodo reproducibility archive created from the submission release.

The GitHub repository retains exact input SHA-256 hashes in `INPUT_MANIFEST.json`, the full curation and descriptor-generation code, configuration and environment files, key machine-readable results, and the ChEMBL licensing/attribution notice.

Until the Zenodo DOI is minted, the complete author-controlled reproducibility archive is retained in the submission package. ChEMBL-derived data remain subject to the ChEMBL CC BY-SA 3.0 terms described in `DATA_LICENSE_NOTICE.md`.
